# Experiment findings

The named experiment folders preserve the original reports and scores. They
are historical snapshots, including unfavourable results and caveats; no scores
were removed to make the model look better. Commands inside those reports refer
to the archived prototype layout.

The current reference pipeline is described in the project README. Running its
training command writes current_pipeline/rainfall and current_pipeline/spi
metadata and metrics, while large artifacts remain locally under artifacts/.

The API, exploratory model-search scripts and GRIB forecast experiments were
archived so teammates see one clear model-building workflow. They can be
recovered from archive/legacy or the pre-cleanup ZIP snapshot.
